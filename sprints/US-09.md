# US-09: Admin xem danh sách đơn hàng đã đặt

> Bản đề xuất 2026-11-18, chờ người dùng chốt Q24 (US-10 tạo đơn), Q29 (chỉ xem, không đổi trạng thái), Q32 (`design/flows/README.md` mục 7).

## Bối cảnh
- Epic: Mua sắm & Giỏ hàng (Epic 4).
- Vai trò: Admin (`profiles.role = 'admin'`, đọc từ DB – D19).
- Mục tiêu: Xem các đơn người mua đã đặt (US-10) để xử lý ngoài hệ thống (gọi điện, giao hàng COD).

## Phạm vi
- `/admin/orders`: danh sách đơn mới nhất trước, **phân trang** 20 đơn/trang, **lọc theo trạng thái**; cột Mã đơn, Ngày đặt, Khách (tên + email), Người nhận, Số món, Tổng tiền, Trạng thái.
- `/admin/orders/:id`: chi tiết đơn (người nhận, SĐT, địa chỉ, ghi chú, phương thức COD, các dòng snapshot, tổng).
- Mục "Đơn hàng" trong menu `AdminLayout`.
- Ngoài phạm vi (Q29): đổi trạng thái, huỷ, sửa đơn; tìm kiếm theo mã/email; xuất CSV; thống kê doanh thu; thông báo đơn mới.
- Thiết kế chi tiết: `design/flows/cart-and-orders.md` mục 2, 3, 9; bảng `design/database/schema.md` mục 16–17.

## Luồng chính (happy path)
1. Admin vào `AccountMenu` → "Quản trị" → menu "Đơn hàng" → `/admin/orders` → `GET /api/admin/orders?page=1&pageSize=20`.
2. Bảng hiện đơn mới nhất trước, badge "Chờ xử lý"; dưới bảng "Trang 1/3" + Trước/Sau.
3. Chọn lọc "Chờ xử lý" → URL `?status=pending&page=1` → tải lại.
4. Bấm mã `DH000012` → `/admin/orders/:id` → `GET /api/admin/orders/:id` → chi tiết; "← Danh sách đơn" giữ nguyên bộ lọc và trang.

## Luồng lỗi cần xử lý
- Guest → `/login?redirect=/admin/orders…`; user thường → trang 403 (UI) / 403 `FORBIDDEN` (API); bị hạ quyền giữa phiên → 403 → `ForbiddenPage`.
- Chưa có đơn → `EmptyState` "Chưa có đơn hàng nào"; lọc không có kết quả → `EmptyState` + "Xem tất cả".
- Query sai trên URL (`status=abc`, `page=0`) → 400 `VALIDATION_ERROR` → UI bỏ tham số sai (replace URL) và tải lại; `page` vượt tổng trang → 200 danh sách rỗng → UI về trang cuối.
- Đơn không tồn tại → 404 `ORDER_NOT_FOUND` → `EmptyState` + link về danh sách.
- 500 / mạng → `ErrorState` + Thử lại.
- Dòng sản phẩm đã bị xoá → nhãn "Sản phẩm đã ngừng bán", ô ảnh giữ chỗ, tên/giá snapshot vẫn đúng.

## Dữ liệu & validate
- `status` (tuỳ chọn): `pending | confirmed | shipping | completed | cancelled`; nhãn: Chờ xử lý / Đã xác nhận / Đang giao / Hoàn tất / Đã huỷ (Sprint 4 chỉ có `pending`).
- `page`: số nguyên ≥ 1 (mặc định 1); `pageSize`: 1–50 (mặc định 20).
- Sắp xếp cố định `created_at desc, id desc`. Ngày giờ `dd/MM/yyyy HH:mm` giờ VN; tiền `formatVnd`.
- Danh sách **không** trả SĐT/địa chỉ/ghi chú (chỉ trang chi tiết).

## API
| Method | Path | Kết quả |
|--------|------|---------|
| GET | `/api/admin/orders?status=&page=&pageSize=` | 200 `{ orders: AdminOrderSummary[], pagination: { page, pageSize, total, totalPages } }` · 400 · 401 · 403 |
| GET | `/api/admin/orders/:id` | 200 `{ order: AdminOrder }` · 401 · 403 · 404 `ORDER_NOT_FOUND` |

## Acceptance Criteria
- Admin thấy mọi đơn (của mọi user, kể cả đơn admin tự đặt), mới nhất trước; `pagination.total` đúng số đơn; trang 2 không lặp/thiếu đơn so với trang 1.
- Lọc trạng thái trả đúng tập đơn; URL giữ `?status&page` qua reload và nút Back.
- Chi tiết hiển thị đúng thông tin giao hàng, dòng snapshot và tổng khớp lúc đặt (kể cả khi sản phẩm sau đó bị đổi giá/xoá).
- User thường gọi API admin đơn → 403; guest → 401.
- Response danh sách không chứa `phone`, `shippingAddress`, `note`; không response nào chứa `profile_id`, `idempotency_key`, `image_path`.
- Bảng desktop / thẻ mobile, 375px không cuộn ngang; badge trạng thái có chữ; đủ 4 trạng thái loading / rỗng / lỗi / có dữ liệu.

## Phi chức năng
- Bảo mật: `requireAuth` → `requireAdmin` (role từ DB); select cột tường minh; dữ liệu cá nhân của người mua chỉ ở trang chi tiết; không log.
- Hiệu năng: danh sách < 500 ms với vài nghìn đơn (index `orders_status_created_idx`, `orders_created_idx`; `count: 'exact'` chấp nhận ở quy mô demo).
- Tái sử dụng: `AdminLayout`, `EmptyState`, `ErrorState`, mẫu bảng desktop / thẻ mobile của `components/admin/ProductList.jsx` (design-system mục "Thành phần admin dùng chung" mô tả `DataTable`/`Badge`/`SkeletonRows` nhưng code hiện **chưa** có file riêng – agent-uiux quyết định tách hay không); thêm `Pagination` dùng chung.
