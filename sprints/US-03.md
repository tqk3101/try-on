# US-03: Quản lý danh mục sản phẩm (Admin)

## Bối cảnh
- Epic: Quản lý kho hàng (Epic 2).
- Vai trò: Admin (`profiles.role = 'admin'`).
- Mục tiêu: Quản lý danh mục (Áo thun, Váy, Quần Jeans…) để phân loại sản phẩm; Sprint 3 dùng danh mục làm điểm vào phòng thử đồ.

## Phạm vi
- Xem danh sách danh mục (tên, slug, số sản phẩm, ngày tạo).
- Thêm, đổi tên, xoá danh mục. Slug do hệ thống sinh từ tên.
- Chỉ admin truy cập khu vực `/admin` và API `/api/admin/*`; role kiểm tra từ DB.
- Ngoài phạm vi: sắp xếp thủ công, danh mục con, ẩn/hiện danh mục, ảnh danh mục.
- Thiết kế chi tiết: `design/flows/category-management.md`; bảng `design/database/schema.md` mục 10.

## Luồng chính (happy path)
- Admin đăng nhập → vào `/admin/categories` → client gọi `GET /api/admin/categories` → hiển thị bảng (3 danh mục seed theo thứ tự tạo).
- Thêm: bấm "Thêm danh mục" → nhập tên → Lưu → `POST` → 201 → dòng mới xuất hiện cuối bảng, toast "Đã lưu danh mục."
- Sửa: bấm "Sửa" → đổi tên → Lưu → `PUT /:id` → 200 → bảng cập nhật tên + slug mới.
- Xoá: bấm "Xoá" trên danh mục không có sản phẩm → xác nhận → `DELETE /:id` → 200 → dòng biến mất, toast "Đã xoá danh mục."

## Luồng lỗi cần xử lý
- Chưa đăng nhập / token hết hạn → về `/login?redirect=…` (401). Đăng nhập nhưng không phải admin → trang 403, API trả 403 `FORBIDDEN`.
- Tên rỗng / chỉ khoảng trắng / quá 50 ký tự / không có chữ hoặc số → 400 `VALIDATION_ERROR`, lỗi dưới ô tên.
- Trùng tên không phân biệt hoa thường ("váy" khi đã có "Váy") hoặc trùng slug ("Vay" khi đã có "Váy") → 409 `CATEGORY_EXISTS` "Danh mục này đã tồn tại."
- Xoá danh mục còn sản phẩm → UI báo trước theo `productCount`; server vẫn chặn 409 `CATEGORY_NOT_EMPTY` (kể cả race).
- Danh mục đã bị xoá ở tab khác → 404 `CATEGORY_NOT_FOUND` → toast + tải lại danh sách.
- Lỗi mạng/server → thông báo thân thiện, giữ dữ liệu đang nhập, không lộ chi tiết kỹ thuật.

## Dữ liệu & validate
- Tên: bắt buộc; chuẩn hoá NFC, trim, gộp khoảng trắng; 1–50 ký tự; unique theo `lower(name)`.
- Slug: server sinh (bỏ dấu tiếng Việt, `đ`→`d`, lowercase, ký tự khác → `-`), unique, sinh lại khi đổi tên; client không gửi.
- Sắp xếp danh sách: theo ngày tạo tăng dần. Không phân trang.

## API
Chi tiết request/response/mã lỗi: `design/flows/category-management.md` mục 3; tóm tắt ở `design/flows/README.md` mục 3.

| Method | Path | Kết quả |
|--------|------|---------|
| GET | `/api/admin/categories` | 200 `{ categories: AdminCategory[] }` |
| POST | `/api/admin/categories` | 201 `{ category }` · 400 · 409 `CATEGORY_EXISTS` |
| PUT | `/api/admin/categories/:id` | 200 `{ category }` · 400 · 404 · 409 |
| DELETE | `/api/admin/categories/:id` | 200 `{ id }` · 404 · 409 `CATEGORY_NOT_EMPTY` |
| GET | `/api/categories` (Task 7, mọi user đã đăng nhập) | 200 `{ categories: [{ id, name, slug }] }` |

Mọi API admin: 401 (`AUTH_REQUIRED` / `TOKEN_EXPIRED` / `INVALID_TOKEN`), 403 `FORBIDDEN`, 500 `INTERNAL_ERROR`.

## Acceptance Criteria (kết hợp sprint backlog Task 3, 4)
- Guest vào `/admin/*` → `/login?redirect=`; user thường → trang 403; admin vào được.
- API `/api/admin/categories*` trả 401 khi không/sai token, 403 với user thường, kể cả khi JWT cũ còn ghi role khác (role đọc từ DB).
- Admin thêm, sửa, xoá được danh mục; dữ liệu còn nguyên sau reload.
- Trùng tên (không phân biệt hoa thường) bị chặn với thông báo rõ.
- Xoá có hộp thoại xác nhận; danh mục còn sản phẩm không xoá được (409), thông báo hướng dẫn xoá/chuyển sản phẩm trước.
- Response đúng envelope `{ success, data }` / `{ success: false, error: { code, message, fields? } }`; không lộ lỗi DB.

## Phi chức năng
- Bảo mật: `requireAuth` → `requireAdmin` (SELECT role từ DB) cho mọi `/api/admin/*`; frontend guard chỉ để UX, không thay kiểm tra server.
- Toàn vẹn: unique và FK `ON DELETE RESTRICT` ở DB là lớp cuối; backend bắt `23505`/`23503` để chống race.
- UX: không cập nhật lạc quan; chặn bấm lặp; Enter = Lưu, Esc = Huỷ; trạng thái loading/rỗng/lỗi rõ ràng; hoạt động trên desktop và mobile cơ bản (bảng chuyển dạng thẻ trên màn hẹp – agent-uiux chốt).
- Hiệu năng: danh sách 1 truy vấn (embed count), < 300 ms ở quy mô hiện tại.
